# Shelf - Personal Reading List App

## Description

Shelf is a flask web application that allow users to create and manage their personal reading list.

Users can create an account, login, add books, update reading status, and delete books from their personal library.

## Features
-User Registration
-User login log out 
-Password hashing
-Personal dashboard
-Add books to readidng list
-Edit reading status
-Delete books 
-user-specific book management
-Responsive styling with custom

## Technologies Used

-Python
-flask
-Flask-SQLALCHEMY
-Flask-Login
-Sqlite
-HTML
-CSS
-Jinja2 templates
